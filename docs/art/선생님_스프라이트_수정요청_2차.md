# 별지기 선생님 스프라이트 2차 수정 요청

첨부한 선생님 시트(1차)를 기준으로 **아래 "고칠 것"만** 고쳐 주세요.

---

## 1. 유지할 것 (아주 좋음)

- 갈색 단발, 빨간 머플러, 겨자색 코트, 남색 니트, 흐린 이름표, 빨간 랜턴
- 칸 배치(6열 × 4행)와 모든 동작: 대기, 걷기, 손 흔들기, 랜턴 건네기, 하늘 보기
- 표정 5종 (기본, 그리움, 진지, 놀람, 감동)

---

## 2. 고칠 것

| # | 지금 문제 | 이렇게 고쳐 주세요 |
|---|---|---|
| 1 | **아이 비율**(머리가 몸의 절반 가까이)이라 어른이 아니라 코트 입은 플레이어로 보임 | **어른 비율로**: 머리는 키의 약 1/3. 다리와 몸통을 길게, 어깨를 넓게 |
| 2 | 얼굴이 플레이어와 완전히 같아 아이 얼굴로 보임 | 같은 눈 색, 같은 머리 모양은 유지하되 **어른 얼굴로**: 눈을 조금 작고 가늘게, 턱선을 갸름하게, 볼 홍조는 없이 |
| 3 | 키 | 같은 칸 크기 안에서 **플레이어보다 약 35% 크게** 보이도록 |

- 목표: 처음 보면 "다정한 어른 선생님", 마지막 장면에서 다시 보면 "아, 어른이 된 플레이어였구나!" 하고 알아볼 정도의 닮음

---

## 3. 공통 규칙

- 파일: **PNG**
- 배경: **단색 #00FF00** 하나만. 그림자, 빛 번짐, 효과 없이
- 모든 칸 같은 크기, 캐릭터 크기와 발끝 높이 통일
- 모든 동작은 **오른쪽**을 봄 (3/4 측면). 표정 칸만 정면
- 짙은 색 외곽선, 2~3단계 음영, 빛 방향은 왼쪽 위
