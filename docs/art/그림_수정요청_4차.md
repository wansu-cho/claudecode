# 그림 수정 요청서 (4차): 돔, LX200, 창고

이미 게임에 들어간 그림 중 **다시 그리면 확실히 좋아지는 3가지**입니다. 한 번에 하나씩 요청해 주세요.
모든 그림은 **첨부한 플레이어 시트, 지금 그림과 같은 그림체, 같은 픽셀 크기**입니다.

## 공통 규칙 (모든 요청에 함께 붙여 넣기)

- 파일: PNG
- 기준: **플레이어 키 = 약 220픽셀**
- 배경: **단색 #00FF00** (그림 3 창고 배경은 배경 그림이라 초록 없음)
- 그림자, 빛 번짐 효과를 초록 위에 그리지 않기
- **글자, 상표, 로고 없이**
- 사람은 그리지 않기
- 짙은 색 외곽선, 2~3단계 음영, 빛 방향은 왼쪽 위
- 외곽선 굵기와 픽셀 크기가 첨부한 그림과 같게

## 요청 순서 (추천)

| 순서 | 그림 | 이유 |
|---|---|---|
| 1 | 그림 1 LX200 단독 | 이 망원경 모양이 정해져야 돔 속 망원경도 같게 그릴 수 있음 |
| 2 | 그림 2 돔 | 그림 1을 첨부해서 같은 망원경으로 |
| 3 | 그림 3 창고 배경 | 따로 해도 됨 |

## 그림 1. 돔 안의 망원경 (Meade LX200 ACF 16인치 느낌)

- 첨부: 플레이어 시트, **`LX200_현재.png`** (그림체 참고), **천문대 LX200 실물 사진** (있으면 가장 좋음)
- 실물 사진을 첨부할 때 함께 적기: **"사진의 상표와 글자는 그리지 말 것"**

**고칠 점**: 지난 그림은 경통 모양(짧고 굵은 원통, 앞면 보정판)은 아주 좋았지만, 마운트가 **한쪽 팔**이었습니다. 실제 LX200 16인치는 **양쪽 팔(두 갈래) 포크**로 경통을 양옆에서 잡습니다.

- 이미지: **2048 × 1024**, #00FF00 배경, **옆에서 본 모습**, 바닥선은 아래에서 약 5% 위
- 크기 (플레이어 키 220픽셀 기준)

| 부분 | 크기 | 설명 |
|---|---|---|
| 전체 높이 | **1.6배 (350픽셀)** | 바닥부터 경통 위 끝까지 |
| 경통 | 굵기 **0.35배 (77픽셀)**, 길이 **0.65배 (145픽셀)** | **짧고 굵은 검은 원통**, 앞뒤 끝에 은색 테두리 |
| 경통 앞면 | | **유리 보정판으로 막혀 있고, 가운데에 작은 검은 원(부경 받침)** |
| 마운트 | | **U자 모양의 두 갈래 포크**: 두 팔이 경통 양옆의 축을 잡음. 포크 아래는 둥근 받침 |
| 기둥(피어) | | 굵은 금속 기둥, 아래에 볼트가 박힌 넓은 바닥판 |
| 작은 부품 | | 경통 위의 작은 파인더 망원경, 경통 뒤쪽의 접안렌즈 |

- 경통은 **오른쪽 위 약 30°**를 향함

## 그림 2. 돔 (틈 속에 LX200)

- 첨부: 플레이어 시트, **`돔_현재.png`**, **그림 1에서 받은 LX200**
- 함께 적기: **"첨부한 돔 그림과 모양, 크기, 색, 문, 등, 리벳을 똑같이 그리고, 틈 안의 망원경만 바꿔 주세요."**

**고칠 점**: 지난 그림의 틈 속 망원경은 깔때기처럼 앞이 넓어지는 모양이었습니다. 돔 안에 있는 망원경은 그림 1의 LX200이어야 합니다.

- 이미지: **2048 × 1024**, #00FF00 배경, 돔 하나만, 바닥선은 아래에서 약 5% 위
- 크기는 지난 그림과 같게: 너비 **4.7배 (1030)**, 높이 **3.9배 (860)**, 문 높이 **1.3배 (285)**
- **틈 안쪽**
  - 짙은 남색의 어두운 돔 내부 (#00FF00 아님)
  - 그 안에 **그림 1과 같은 LX200**: 짧고 굵은 검은 경통이 **위쪽(약 60°)을 향해** 틈 사이로 보임. 앞면 보정판과 가운데 작은 원
  - 경통은 **틈 너비 안에 다 들어오게** (틈 밖 돔 겉면 위로 튀어나오지 않게)
  - 포크와 기둥은 원통 받침에 가려 거의 보이지 않아도 됨
- 틈 양옆의 금속 띠(리벳 줄)는 지난 그림과 같은 굵기로

## 그림 3. 1층 창고·실습실 배경

- 첨부: 플레이어 시트, **`창고_수정위치.png`** (빨간 네모가 바꿀 곳)
- 함께 적기: **"첨부한 창고 그림을 그대로 두고, 빨간 네모 안만 바꿔 주세요. 빨간 네모 선은 그리지 마세요."**

**고칠 점**: 빨간 네모 자리는 원래 "지하로 가는 문"을 놓으려고 비워 둔 벽입니다. 지하 입구가 책방 책장으로 옮겨 가서, 지금은 아무것도 없는 빈 벽으로 남았습니다.

- 이미지: **1430 × 605** (지금과 같은 크기)
- 빨간 네모 안 (그림 오른쪽 약 76%~95%)에 그릴 것: **실습실다운 물건**
  - 바닥에 쌓인 **망원경 상자 2~3개** (긴 나무 상자, 금속 걸쇠)
  - 그 뒤 벽에 **작은 선반 하나**: 별자리 판(원형 성도판), 작은 행성 모형, 종이 상자
  - 높이는 왼쪽 선반들과 비슷하게 (바닥에서 벽 위쪽 약 70%까지)
- **바꾸지 말 것**
  - 빨간 네모 바깥의 모든 것 (선반, 작업대, 공구판, 조명, 기둥)
  - 바닥 높이와 벽 색
  - 작업대 위는 비워 두기 (게임이 종이 앙부일구를 올려놓음)
  - 왼쪽 선반 앞(약 21%) 바닥은 비워 두기 (게임이 지구 공전 모형을 놓음)
