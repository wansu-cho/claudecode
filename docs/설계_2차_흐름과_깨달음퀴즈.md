## 2. 깨달음 퀴즈: 예측 → 관찰 → 설명

### 2-1. 뼈대
관측 장치 하나마다 세 단계를 거칩니다. 퀴즈를 푸는 동안 시간은 멈춥니다.

1. **예측** (보기 전, 고르기): "어떻게 될까?" 그림 3장 중 하나 고르기. **틀려도 벌이 없습니다.** 예측은 맞히는 게 목적이 아니라 궁금하게 만드는 것이 목적이기 때문입니다.
2. **관찰** (관측 화면 안, 직접 해 보기): 지금처럼 별을 잇거나 시간을 넘기며 보고, **눈으로 찾아 누르는 활동** 한 가지를 합니다.
3. **설명** (관측 뒤, 빈칸 또는 짝 맞추기): 맞히면 "★ 깨달음!" 카드가 나오고 일지에 적힙니다.
   - 처음 틀리면: "다시 볼까?" (관측 화면 다시 보기)
   - 두 번 틀리면: 초성 힌트
   - 세 번 틀리면: 보기를 2개로 줄임

근거:
- 예측-관찰-설명(POE): White & Gunstone (1992), *Probing Understanding*.
- 떠올려 답하기의 기억 효과: Roediger & Karpicke (2006), *Psychological Science* 17(3).
- 틀린 보기로 쓸 오개념: Vosniadou & Brewer (1992), *Cognitive Psychology* 24(4).

### 2-2. 증거별 퀴즈 초안

| 증거 | ① 예측 (고르기) | ② 관찰 (찾아 누르기) | ③ 설명 |
|---|---|---|---|
| 해넘이 | 해는 어떻게 사라질까? (갑자기 꺼짐 / 비스듬히 내려감 / 위로 올라감) | 30분 간격 해 위치 3개 중 "처음 해"를 누르기 | 교재 173쪽 그림처럼 **북극 위에서 본 지구**: 해를 등지는 쪽으로 사람을 데려가려면 지구를 어느 쪽으로 돌려야 할까? (시계 방향 / **시계 반대 방향**) → 빈칸: 지구가 ( 서 )에서 ( 동 )으로 자전하기 때문에, 해는 ( 동 )에서 떠서 ( 서 )로 지는 것처럼 보인다 |
| 푸코 진자 | 1시간 뒤 진자 방향은? (그대로 / 조금 돌아감 / 멈춤) | 바닥 눈금에서 처음 방향과 지금 방향 누르기 | **왜 자전의 증거인가**를 두 단계로: ① 고르기 "진자를 옆으로 돌린 힘이 있었을까?" (없다: 아무도 건드리지 않았고, 흔들리는 추는 처음 방향을 지키려 함) ② 위에서 본 화면에서 **바닥 판만 천천히 돌려 보는 장면**을 보고 고르기 "돌아간 것은?" (진자 / **진자 아래의 땅**) → 빈칸: 진자 아래의 땅이 돈다 = 지구가 ( 자전 )한다. 심화: 북극이라면 1시간에 15°, 이 섬(북위 34°)에서는 약 8° |
| 일주운동 | 1시간 뒤 북두칠성은 어디에? (그림 3장) | 장노출 사진에서 "거의 움직이지 않은 별" 누르기 | 교재 174쪽 5지선다: 지구가 한 번 자전하는 데 걸리는 시간 (24시간) |
| 숨은 북두칠성 | 겨울 초저녁 북쪽 하늘에 북두칠성이 보일까? (예 / 아니요) | 북쪽 하늘에서 W자 별자리 찾아 누르기 | 교재 178쪽 짝 맞추기: 봄·여름 저녁 ↔ 북두칠성이 높이 / 가을·겨울 저녁 ↔ 카시오페이아가 높이 → 빈칸: 겨울 초저녁엔 ( 카시오페이아 )자리로 북극성을 찾는다 |
| 북극성 찾기 (2가지) | 없음 (방법 자체가 활동) | 교재 178쪽 그대로: 두 별 잇기 → 5칸 늘이기 → 북극성 누르기. **카시오페이아로 찾은 뒤 북극성 표시는 다시 지움** (북두칠성 방법에서도 직접 찾아 누르게) | 빈칸: 국자 끝 두 별 거리의 ( 5 )배 |
| 수평선 너머의 배 | 교재 170쪽 **짝 맞추기**: 네모·둥근·세모 지구 ↔ 배가 보이는 모습 | 쌍안경으로 "먼저 사라진 부분" 누르기 (아랫부분) | 고르기: 쌍안경으로 크게 봐도 안 보이는 까닭? (멀어서 / **둥근 바다에 가려서**) |
| 월식 그림자 | 교재 171쪽: 달에 비친 그림자는 누구의 것? 세모 / 동그라미 / 네모 지구 | **남쪽 하늘을 기준으로** 달이 동→남→서로 움직이는 화면. 시각마다 망원경으로 찍은 달이 하늘 길을 따라 쌓여 교재 171쪽 같은 **연속 사진**이 됨. 각 장에서 그림자 가장자리 따라 긋기 | 빈칸: 지구 그림자가 달을 가리는 ( 월식 )으로 둥근 지구를 알 수 있다 (교재 179쪽 ①번) |
| 노인성 | 남쪽으로 가면 남쪽 별은? (더 높이 / 그대로 / 더 낮게) | 관측 전에는 테오가 부르는 그리스 이름 **"카노푸스"**만 씀 → 돔에서 남쪽 수평선의 카노푸스를 찾아 누르기 → LX200으로 확대 → 휘가 알아봄: "그건 **노인성(老人星)**이오! 보이면 나라가 태평하다 하였소." (사마천 『사기』 「천관서」) → **같은 별, 두 문화의 이름** | 짝 맞추기: 서울(37.6°) / 이 섬(34°) / 제주(33.5°) ↔ 보임·안 보임 |
| 기울어진 자전축 | 6월과 12월, 해가 더 높이 뜨는 달은? | 공전 모형에서 축을 세우고 계절 비교 | 빈칸: 계절은 ( 자전축 )이 기울어서 생긴다 |
| 근일점 | 지구가 태양에 가장 가까운 달은? (7월 / **1월**) | 공전 모형에서 가장 가까운 날 찾기 | 교재 175쪽 5지선다: 공전 주기 (365일) |

### 2-3. 손님 설득은 그대로
손님 설득은 지금처럼 **필요한 증거를 골라 보여 주는 방식**을 유지합니다.
퀴즈로 얻은 깨달음을 손님 앞에서 다시 쓰는 구조라서, 한 번 더 떠올리는 연습이 됩니다.

## 3. 새 흐름

1. **15:30 마당 (프롤로그)**: 선생님이 손전등을 쥐여 줌. 이때부터 손전등이 손에 보임.
2. **16:00 강의실**: 짧은 수업 → "수업 중 깜빡 잠이 들었다" (화면 어두워짐)
3. **17:00 강의실에서 깨어남**: 친구들은 깊이 잠들어 말을 걸어도 일어나지 않음.
4. **사무실 책상 쪽지** (플레이어가 직접 찾음)
   - 내용 예: "해가 지는 모습을 옥상 전망대에서 지켜보렴. 그리고 잊지 마. 해가 다시 뜨면, 오늘을 기억하는 건 너와 이 일지뿐일 거야."
   - 반복을 귀띔하되, 아직 정체는 알려 주지 않습니다.
5. **손님**: 물건에 말을 걸어야 깨어남 (깨어나는 동작). 그 뒤로는 그 물건이 빈 모습.
   - 시간 제한은 그대로입니다: 연락선 19:30, 물때 21:30, 월식 21:22~.
   - 한 번 깨운 손님은 **다음 밤부터 17:00에 이미 돌아다님**.
6. **해가 뜨면 되감기 (24번)**: 되감기 기호 없이 이렇게 보여 줍니다.
   - 하늘의 해·달·별이 빠르게 거꾸로 돌고, 시계 바늘도 거꾸로 돕니다.
   - **거꾸로 그려지는 일주 사진**(호가 짧아지며 점으로 돌아감)이 나온 뒤 17:00.
7. **두 번째 밤, 루프 깨닫기 (23번)**: 객관식 확인
   - 질문: "지금 무슨 일이 일어나고 있는 걸까?"
   - 보기: ① 꿈을 꾸는 중 ② **같은 밤이 되풀이되는 중** ③ 시계가 고장 남 ④ 친구들의 장난
   - 틀리면: "관측 일지를 다시 펼쳐 보자. 어젯밤 기록이 남아 있는데…" 같은 힌트
8. **모두 모았을 때 (28번)**
   - 손님 6명이 각자의 물건으로 돌아가고, 물건이 하나씩 빛남.
   - 마지막으로 책방 책장이 반짝임 → "책방 책장을 살펴봐야겠어."
9. **책방 책장 (17번)**
   - 손님을 다 모으기 전: "…책장이 흔들린다."
   - 다 모은 뒤: 교재 179쪽 같은 **"한 장 정리" 빈칸 5문항** → "책장이 움직인다…!" → 지하 별지기의 방

## 4. 관측 장치 바꾸기

| 장치 | 바뀌는 점 |
|---|---|
| 옥상 서쪽 | **해넘이 전망대** (계단 몇 칸 올라간 전망 데크) |
| 옥상 북쪽 | 망원경 대신 **관측 의자**: 맨눈으로 북쪽 하늘, 일주운동, 북극성 찾기 |
| 옥상 망원경 | **달 관측** 전용: 개기월식의 둥근 그림자 (시야 약 1°, 달 지름 0.5°라 달 전체가 들어옴) |
| 돔 | 남쪽 하늘 넓은 화면 → 별을 누르면 **Meade LX200 ACF 16인치 (구경 406mm, f/10, 초점거리 4064mm)** 화면으로 확대. 26mm 접안렌즈(겉보기 시야 52°) 기준 **약 156배, 실제 시야 약 0.33°** |
| 부두 쌍안경 | 연락선이 아래부터 수평선 너머로 사라지는 모습 (배·바다 그림 새로) |
| 공전 모형, 푸코 진자 | 관측 화면을 새로 디자인 (그림 요청) |

### 돔 망원경으로 누를 수 있는 별 (12월 13일 밤, 남쪽 하늘)
1. **노인성**: 확대해도 점. 낮은 고도라 대기 때문에 무지개색으로 일렁임. "별은 너무 멀어서 아무리 키워도 점"
2. **베텔게우스와 리겔**: 붉은 별과 푸른 별의 색 비교
3. **시리우스**: 하늘에서 가장 밝은 별. 낮게 떠서 색이 빠르게 바뀌며 반짝임 (플레이아데스는 지름 약 2°라 0.33° 시야에 다 들어오지 않아 뺐습니다)
4. **오리온대성운(M42)**: 별이 태어나는 가스 구름, 가운데 **트라페지움**(네 별)이 16인치에서 또렷함

행성은 2141년 위치를 계산해야 해서 이번에는 넣지 않습니다.

## 5. 다음 그림 요청서에 들어갈 것

1. 손전등 없는 플레이어 (대기, 걷기)
2. 천문대 외벽 (밖에서는 외벽, 안에 들어가면 단면이 보이게 서서히 바뀜)
3. 마당 흙 단면 잘라 내기 + **바닷가 돌 축대**로 마당과 부두 잇기
4. 돔 다시 (지금의 2배, 오른쪽, 플레이어보다 큰 문, 틈 안쪽은 어둡게 망원경이 보이게)
5. 나선 계단 출구 다시
