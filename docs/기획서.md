# 별지기의 마지막 밤: 기획서 (시제품 기준)

수업이 끝난 뒤 아이들이 집에서 폰이나 컴퓨터로 혼자 하는 시간 루프 천문 탐험 게임입니다.

## 1. 기본 설정

| 항목 | 내용 |
|---|---|
| 대상 | 어린이천문대에 다니는 초등학교 4학년 |
| 방식 | 1인 플레이, 시간 루프, 멀티 엔딩 |
| 무대 | 외딴섬 '별빛섬 어린이천문대'의 겨울 별 캠프 (12월 20일 밤, 북위 34°) |
| 한 밤의 길이 | 17:30 ~ 07:30. 실제 시간 약 4분 40초 (게임 1분 = 실제 1/3초) |
| 화면 | 640×360 (시제품). 정식 버전은 960×540 예정 |

## 2. 이야기

- 별 캠프 저녁, 천문대 선생님이 쪽지 한 장만 남기고 사라집니다.
  > "하늘의 진짜 모습을 알아낸 사람만이, 이 밤을 끝낼 수 있어."
- 해가 뜨는 순간, 모든 것이 다시 해 질 녘으로 돌아갑니다.
- 전시실의 옛 천문 유물 복제품 속 사람들이 깨어납니다. 이들도 같은 밤에 갇혀 있습니다.
- 주인공은 하늘을 관측해 증거를 모으고, 그 증거로 사람들을 설득해 아침으로 보내 줍니다.
- 아침으로 돌아간 사람은 '우주 주소' 조각을 하나씩 남깁니다. 7조각을 모으면 지하 문이 열립니다.
- 반전: 선생님은 어른이 된 주인공 자신입니다. (같은 밤에 같은 사람이 둘 있을 수 없어서 사라졌던 것)

## 3. 공간 구성

| 곳 | 들어 있는 것 |
|---|---|
| 항구 | 돌쇠의 배 |
| 천문대 마당 | 벤치(기다리기), 안내판 |
| 3층 옥상 관측 데크 | 망원경, 돔 (밤이 시작되는 곳) |
| 2층 전시실 '옛사람들의 하늘' | 누트 여신 그림, 천상열차분야지도, 아직 잠든 유물(점토판, 죽간, 그리스 도기) |
| 1층 로비 | 푸코 진자, 선생님 책상, 지하로 가는 문 |
| 지하 1층 (잠김) | 일곱 칸 자물쇠 문. 우주 주소 조각이 모이면 칸이 하나씩 빛남 |

- 층 이동은 왼쪽 계단에서 가고 싶은 층을 고릅니다.
- 바깥 지도는 이전보다 약 40% 짧습니다.

## 4. 루프 규칙

| 남는 것 | 지워지는 것 |
|---|---|
| 관측 일지(알아낸 사실), 아침으로 돌아간 사람, 몇 번째 밤인지 | 이번 밤의 기록(진자 기록, 사진), 사람들과의 대화 |

- 사건은 정해진 시각에만 일어납니다. 그래서 루프를 반복할수록 아이가 스스로 계획을 세우게 됩니다.
- 막힌 아이를 위해 다음 밤이 시작될 때 쪽지 뒷면에 힌트가 하나씩 생깁니다.

## 5. 시제품 범위 (케티 + 돌쇠)

### 등장인물 시간표

| 인물 | 깨어나는 곳 | 시간표 | 믿음 | 설득에 필요한 증거 |
|---|---|---|---|---|
| 케티 (이집트 서기의 딸) | 누트 여신 그림 | 18:00 2층 전시실 → 21:00부터 3층 옥상 | 누트 여신이 라를 삼켜서 밤이 온다 | **진자 + 도는 하늘** (둘 다 있어야 함) |
| 돌쇠 (조선 뱃사람) | 천상열차분야지도 | 19:00 2층 전시실 → 20:00~23:00 항구 | 나침반을 잃어 북쪽을 모른다 | **북극성 찾기** (23시 물때 전에) |

### 관측 활동

| 활동 | 장소 | 방법 | 얻는 사실 |
|---|---|---|---|
| 푸코 진자 | 1층 로비 | 기록 → 1시간 이상 뒤 다시 기록 (1시간에 약 8.4°) | 돌아가는 진자 |
| 하늘 사진 | 3층 옥상 망원경 | 사진 → 1시간 이상 뒤 다시 사진 (1시간에 약 15°) | 도는 하늘 |
| 북극성 찾기 | 망원경 | 카시오페이아 W의 바깥 두 변 → 가운데 별 → 5배 / 북두칠성 국자 끝 두 별 → 5배 | 북극성 찾기 (2가지) |
| 하늘 살펴보기 | 망원경 | 초저녁에 열어 보기 | 숨은 북두칠성 |
| 기다리기 | 벤치 | 30분 / 1시간 건너뛰기 | — |

### 천문 사실 확인
- 별 위치는 실제 적경·적위와 2026년 12월 20일, 북위 34°, 동경 127.5° 기준으로 계산합니다.
- 초저녁(19~21시)에는 북두칠성이 북북동쪽 지평선 근처에 낮게 있어 산에 가려지고, 카시오페이아자리는 높이 떠 있습니다. 자정 무렵부터 북두칠성이 높이 올라옵니다.
- 푸코 진자의 회전 속도: 15° × sin(34°) ≈ 8.4°/시간, 북반구에서는 위에서 볼 때 시계 방향입니다.

## 6. 조작

| 동작 | 키보드 | 폰 (가상 키패드, 화면에 버튼 없음) |
|---|---|---|
| 이동 | ← → 또는 A D | 화면 왼쪽을 누른 채 좌우로 끌기 |
| 점프 | Space, W, ↑ | 화면 오른쪽 탭 |
| 확인, 대화 | E, Enter | [눌러서 …] 말풍선 탭 |
| 대사 넘기기 | Space, Enter | 화면 탭 |
| 관측 일지 | J | 위쪽 '관측 일지' 버튼 |
| 망원경에서 사진 | P | '사진 찍기' |
| 진자 기록 | R | '기록하기' |
| 나가기 | Esc | '나가기' |

- 두 번 점프는 이미 만들어 두었고, 나중에 퀘스트 보상으로 열 예정입니다. (`Game.double_jump`)

## 7. 시제품에서 확인할 것

1. 아이들이 **"몇 시에 어디에 있어야 하는지"** 스스로 계획하는 재미를 느끼는가
2. 증거 두 개를 조합해 설득하는 부분이 너무 어렵거나 쉽지 않은가
3. 한 밤 약 4분 40초가 적당한가
4. 이야기(유물에서 깨어난 사람들, 사라진 선생님)에 몰입하는가

## 8. 다음 작업 (제안)

1. 시제품을 아이들 몇 명에게 시켜 보고 반응 기록
2. 나머지 인물(이나, 휘, 테오, 보리) 추가
3. 제미나이 그림으로 교체하고, 기본 해상도 960×540으로 변경
4. 진 엔딩(지하 문, 우주 줌아웃, 선생님의 정체) 제작
5. 두 번 점프를 얻는 퀘스트와, 점프가 필요한 장소 만들기

## 부록: 시제품 정답 (선생님용, 아이들에게는 비밀)

1. 17:30 로비에서 진자 기록
2. 망원경에서 카시오페이아로 북극성 찾기, 사진 찍기
3. 1시간 뒤 진자 다시 기록, 사진 다시 찍기
4. 19:00~20:00 전시실에서 돌쇠 만나기 → 23시 전에 항구에서 북극성 증거 보여 주기
5. 케티에게 '돌아가는 진자' + '도는 하늘'을 함께 보여 주기
