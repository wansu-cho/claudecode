# 별지기의 마지막 밤: 기획서 (시제품 기준)

수업이 끝난 뒤 아이들이 집에서 폰이나 컴퓨터로 혼자 하는 시간 루프 천문 탐험 게임입니다.

## 1. 기본 설정

| 항목 | 내용 |
|---|---|
| 대상 | 어린이천문대에 다니는 초등학교 4학년 |
| 방식 | 1인 플레이, 시간 루프, 멀티 엔딩 |
| 무대 | 외딴섬 '별빛섬 어린이천문대'의 겨울 별 캠프 (2xxx년 12월 13일 밤, 북위 34°). 개기월식이 있는 보름날 |
| 한 밤의 길이 | 17:00 ~ 07:30. 실제 시간 약 4분 50초 (게임 1분 = 실제 1/3초). 사람과 이야기하거나 관측 일지·교재·칠판을 보는 동안에는 시간이 멈춤. 17:00에 시작해야 해넘이(17:17 무렵)를 볼 수 있음 |
| 화면 | 640×360 (시제품). 정식 버전은 960×540 예정 |

## 2. 이야기

- 별 캠프 저녁, 천문대 선생님이 쪽지 한 장만 남기고 사라집니다.
  > "하늘의 진짜 모습을 알아낸 사람만이, 이 밤을 끝낼 수 있어."
- 해가 뜨는 순간, 모든 것이 다시 해 질 녘으로 돌아갑니다.
- 전시실의 옛 천문 유물 복제품 속 사람들이 깨어납니다. 이들도 같은 밤에 갇혀 있습니다.
- 주인공은 하늘을 관측해 증거를 모으고, 그 증거로 사람들을 설득해 아침으로 보내 줍니다.
- 아침으로 돌아간 사람은 '우주 주소' 조각을 하나씩 남깁니다. 7조각을 모으면 지하 문이 열립니다.
- 반전: 선생님은 어른이 된 주인공 자신입니다. (같은 밤에 같은 사람이 둘 있을 수 없어서 사라졌던 것)

## 3. 공간 구성

| 곳 | 들어 있는 것 |
|---|---|
| 천문대 마당 | 벤치(기다리기), 안내판 |
| 항구 | 돌쇠의 배, 섬 연락선(19:30 출항), 부두 쌍안경 |
| 3층 옥상 관측 데크 | 서쪽 난간(해넘이), 북쪽 하늘 망원경, 돔(남쪽 하늘과 달을 보는 큰 망원경). 밤이 시작되는 곳 |
| 2층 강의실 | 칠판(오늘 밤 하늘 시간표), 책상에 엎드려 잠든 캠프 친구들 |
| 1층 책방 | 어린이천문대 교재 9단원 (자전, 일주운동, 북극성 찾기, 지구가 둥근 증거 3가지, 계절, 월식, 우주 주소) |
| 2층 전시실 '옛사람들의 하늘' | 유물 6점: 누트 여신 그림, 천상열차분야지도, 바빌로니아 점토판, 죽간, 그리스 도기, 절기 농사 달력 |
| 1층 로비 | 푸코 진자, 지구 공전 모형, 선생님 책상, 지하로 가는 문 |
| 지하 1층 (잠김) | 일곱 칸 자물쇠 문. 우주 주소 조각이 모이면 칸이 하나씩 빛남 |

- 층 이동은 왼쪽 계단에서 가고 싶은 층을 고릅니다.
- 바깥 지도는 이전보다 약 40% 짧습니다.

## 3-1. 프롤로그 (첫 밤 전)

- 15:30 항구에서 시작해 직접 걸어서 마당의 선생님을 만납니다. (시간은 멈춰 있고, 천문대 문은 닫혀 있음)
- 해를 등진 선생님은 얼굴이 보이지 않고, 목소리가 귀에 익습니다. 오늘 밤 개기월식을 알려 주고 빨간 손전등을 빌려줍니다. ("나도 예전에 누가 빌려줬었거든.")
- 대화가 끝나면 17:00 옥상으로 넘어가고, 선생님이 사라진 밤이 시작됩니다.

## 4. 루프 규칙

| 남는 것 | 지워지는 것 |
|---|---|
| 관측 일지(알아낸 사실), 아침으로 돌아간 사람, 몇 번째 밤인지 | 이번 밤의 기록(진자 기록, 사진), 사람들과의 대화 |

- 사건은 정해진 시각에만 일어납니다. 그래서 루프를 반복할수록 아이가 스스로 계획을 세우게 됩니다.
- 막힌 아이를 위해 다음 밤이 시작될 때 쪽지 뒷면에 힌트가 하나씩 생깁니다.

## 5. 시제품 범위 (케티 + 돌쇠)

### 등장인물 시간표

- 증거는 **필요한 것만 정확히** 보여 줘야 합니다. 엉뚱한 증거가 섞이면 인물이 헷갈려 하며 실패합니다.
- 인물마다 하룻밤에 **믿음 하트 3개**가 있습니다. 틀릴 때마다 하나씩 줄고, 다 잃으면 그날 밤에는 더 이상 증거를 들어 주지 않습니다. (다음 밤에 다시 3개)
- 관측으로 사실을 알아내면 '깨달음!' 카드가 크게 뜨고, 누르면 카드가 관측 일지로 날아갑니다.


| 인물 | 깨어나는 유물 | 시간표 | 믿음 | 설득에 필요한 증거 |
|---|---|---|---|---|
| 케티 (이집트 서기의 딸) | 누트 여신 그림 | 18:00 2층 → 21:00부터 옥상 | 누트 여신이 라를 삼켜서 밤이 온다 | **진자 + 서쪽으로 지는 해** |
| 테오 (그리스, 아리스토텔레스의 제자) | 그리스 도기 | 18:00 1층 로비 → 23:30부터 옥상 | 땅은 둥글지만, 아테네에서는 안 보이는 남쪽 별을 직접 보고 싶다 | **노인성** (힌트도 알려 줌) |
| 이나 (바빌로니아 서기 견습생) | 점토판 | 18:30부터 항구 | 땅은 바다에 둘러싸인 원반, 배는 세상 끝에서 떨어진다 | **수평선 너머의 배** |
| 돌쇠 (조선 뱃사람) | 천상열차분야지도 | 19:00 2층 → 20:00~21:30 항구 | 북두칠성 방법은 아는데 산에 가려 있다. 별이 밤새 도니 믿어도 될지 걱정 | **카시오페이아로 북극성 찾기 + 도는 하늘** (21:30 물때 전) |
| 보리 (조선 농사꾼 딸) | 절기 농사 달력 | 19:00부터 1층 로비 | 여름은 해가 가까워서 덥다 | **가장 가까운 날은 한겨울 + 기울어진 자전축** |
| 휘 (한나라 천문 기록관) | 죽간 | 20:00부터 옥상 | 하늘은 둥글고 땅은 네모나다 | **언제나 둥근 그림자** (오늘 밤 월식을 직접 3번 촬영) |

### 천문 사실 확인
- 날짜는 2141년 12월 13일입니다. (게임 안에서는 '2xxx년'으로만 보여 줌) 2000~2999년 12월 10~25일 사이, 우리나라에서 개기식 전체가 높은 하늘에서 보이는 개기월식 15번 중 하나입니다.
  - 월식: 부분식 시작 21:22, 개기식 22:20~23:52 (가장 깊을 때 23:06, 달 고도 69°), 부분식 끝 00:50 (한국 시각)
  - 계산: ERFA 라이브러리의 달·태양 위치(moon98, epv00)와 단종(Danjon)의 그림자 크기 공식, ΔT(지구 자전이 느려지는 정도) 약 5분. 2010·2011·2028년 월식으로 계산 방법을 검산했습니다(나사 목록과 1분 이내 일치).
- 별 위치는 2000년 좌표에 141년 동안의 세차운동을 보정해 계산합니다 (북위 34°, 동경 127.5°).
- 망원경 화면(북쪽, 돔, 해넘이)은 심사 투영(카메라 사진과 같은 투영)으로 그립니다. 두 별을 잇는 큰 원이 화면에서 곧은 선이 되어 별자리 모양과 길잡이 선이 실제 하늘과 같습니다. 바깥 풍경만 넓게 보여 주려고 방위·고도를 그대로 펼친 투영을 씁니다.
- 북극성 길잡이: 실제 하늘에서 국자 끝 두 별 사이를 약 5.3배(어긋남 약 1.9°), W자 쪽은 약 5.0배(어긋남 약 0.8°) 가면 북극성입니다. 게임에서는 길잡이 선이 북극성에서 끝나도록 다섯 칸을 북극성까지 고르게 나눕니다.
- 초저녁에는 북두칠성이 북북동쪽 산에 가려지고, 카시오페이아자리는 높이 떠 있습니다. 국자 끝 두 별(메라크·두베)은 21:55 무렵 산 위로 올라옵니다. 그래서 돌쇠의 물때(21:30)를 맞추려면 카시오페이아자리를 써야 합니다.
- 해넘이 17:17 무렵(해 중심 기준), 해 뜰 녘 07:30 무렵.
- 푸코 진자의 회전 속도: 15° × sin(34°) ≈ 8.4°/시간, 북반구에서는 위에서 볼 때 시계 방향입니다.
- 노인성(카노푸스, 그날의 적위 −52.8°): 북위 34°에서 최고 고도 약 3.2°, 서울(북위 37.6°)에서는 약 −0.4°, 아테네(북위 38.0°)에서는 약 −0.8°로 뜨지 않습니다.
- 수평선에 가려지는 높이 ≈ (거리 − 6.2 km)² ÷ (2 × 6,371 km). 눈높이 3 m 기준, 대기 굴절은 무시했습니다.
- 근일점(1월 초) 약 1억 4,710만 km, 원일점(7월 초) 약 1억 5,210만 km.

| 점프 | Space, W, ↑ | 화면 오른쪽 탭 |

## 7. 시제품에서 확인할 것

1. 아이들이 **"몇 시에 어디에 있어야 하는지"** 스스로 계획하는 재미를 느끼는가
2. 증거 두 개를 조합해 설득하는 부분이 너무 어렵거나 쉽지 않은가
3. 한 밤 약 4분 50초(대화 중 정지)가 적당한가
4. 이야기(유물에서 깨어난 사람들, 사라진 선생님)에 몰입하는가

## 8. 다음 작업 (제안)

1. 시제품을 아이들 몇 명에게 시켜 보고 반응 기록
2. 나머지 인물(이나, 휘, 테오, 보리) 추가
3. 제미나이 그림으로 교체하고, 기본 해상도 960×540으로 변경
4. 진 엔딩(지하 문, 우주 줌아웃, 선생님의 정체) 제작
5. 두 번 점프를 얻는 퀘스트와, 점프가 필요한 장소 만들기

한 밤 안에 모두 풀 수도 있고, 여러 밤에 나눠 풀어도 됩니다. (관측 일지는 남습니다)

2. 1층 진자 기록, 지구 공전 모형(6월·12월·1월·7월, 자전축 세우기)
3. 옥상 망원경: 카시오페이아로 북극성 찾기, 어두워지면 1시간 장노출 → 1시간 뒤 진자 다시

5. 19:00~21:30 돌쇠(카시오페이아 북극성 + 도는 하늘), 항구에서 이나(배) 설득
6. 1층에서 보리(공전 모형 사실 2개) 설득
7. 21:22~22:20 돔 망원경(달)으로 부분식 사진 3장 (20분 넘는 간격) → 옥상에서 휘(월식), 케티(진자 + 해넘이) 설득
8. 23:38~03:16 돔 남쪽 하늘에서 노인성 → 테오 설득
