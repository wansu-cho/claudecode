# 프로젝트 골든 레코드

어린이천문대 수업용 픽셀 천문 게임입니다. 초등학교 4학년 5~10명이 한 명씩 나와서 20분 안에 함께 플레이합니다.

- 기획 내용: [docs/기획서.md](docs/기획서.md)
- 엔진: Godot 4.5 (GDScript)

## 실행 방법

1. [Godot 엔진 4.5](https://godotengine.org/download)을 내려받습니다. (Standard 버전)
2. Godot을 열고 **가져오기(Import)** 를 누른 뒤, 이 폴더의 `project.godot` 파일을 고릅니다.
3. 편집기 오른쪽 위의 ▶ 버튼(또는 F5)을 누르면 게임이 시작됩니다.

수업용 실행 파일(.exe)을 만들 때는 편집기 메뉴에서 **프로젝트 → 내보내기 → Windows Desktop** 을 고릅니다. 처음 한 번은 내보내기 템플릿을 내려받아야 합니다.

## 진행자(선생님) 키

| 키 | 기능 |
|---|---|
| Enter | 안내 화면 넘기기, 전원 참여 단계 정답 공개 |
| Space | 일시정지 / 계속 |
| H | 힌트 바로 보여 주기 |
| N | 지금 단계(화면) 건너뛰기 |
| B | 예측 보너스 (단계마다 한 번) |
| F11 | 전체 화면 켜기/끄기 |

## 폴더 구성

| 위치 | 내용 |
|---|---|
| `scripts/stage_data.gd` | **이야기, 문제, 설명 글이 모두 여기 있습니다.** 글을 고칠 때는 이 파일만 고치면 됩니다. |
| `scripts/pal.gd` | 색과 글자 크기 |
| `scripts/game_state.gd` | 인원, 단계 배정, 탐사 데이터 |
| `scripts/main.gd` | 게임 전체 흐름과 진행자 키 |
| `scripts/screens/` | 안내 화면, 인원 입력, 위쪽 정보 띠, 마지막 화면 |
| `scripts/stages/` | 단계별 플레이 화면 (북두칠성, 카시오페이아자리, 고르기 문제 등) |
| `assets/fonts/` | 갈무리 픽셀 글꼴 (SIL 오픈 폰트 라이선스, `OFL.md` 참고) |
| `tests/autoplay.gd` | 자동 점검: 한 판을 자동으로 끝까지 플레이해 봅니다 |

## 자동 점검

```
godot --path . --script res://tests/autoplay.gd -- 7
```

7은 참가 인원입니다. 끝까지 문제없이 가면 `AUTOPLAY OK`가 출력됩니다.

## 현재 상태

- 완성: 전체 흐름(인원 입력 → 배정 → 브리핑 → 10단계 → 마지막 화면), 09·10단계(북극성 찾기)
- 고르기 문제로 임시 구현: 03, 04, 05, 07, 08단계
- 제작 예정: 01, 02단계(우주 좌표 추적), 06단계(낮과 밤 만들기), 효과음
